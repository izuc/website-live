# Website.Live

> Transform your ideas into stunning websites with the power of AI.
>
> *This project is a fork of [bolt.diy](https://github.com/stackblitz-labs/bolt.diy), customized and enhanced for Website.Live.*

## Overview

Website.Live is an AI-powered web development platform that revolutionizes how you build websites. Using natural language commands, you can create, modify, and deploy web applications with ease, all while leveraging the power of various AI models.

## ✨ Features

- **🤖 AI-Powered Development**
  - Build websites faster with intelligent AI assistance
  - Support for multiple AI models (OpenAI, Anthropic, Mistral, and more)
  - Natural language commands for code generation and modifications

- **💻 Modern Development Environment**
  - Real-time preview with hot reloading
  - Integrated terminal with command execution
  - Built-in code editor with syntax highlighting
  - File management system with drag-and-drop support

- **🚀 Advanced Capabilities**
  - Instant deployment options
  - Version control with code history
  - Image attachment support for visual context
  - Error detection and auto-fix suggestions
  - Multiple terminal support for complex workflows

- **🛠️ Developer Tools**
  - TypeScript support
  - Modern tech stack with best practices
  - Comprehensive API integrations
  - Docker support for containerized development

## 🚀 Getting Started

1. Visit [Website.Live](https://website.live)
2. Choose your preferred AI model
3. Start building with natural language commands
4. Preview and deploy your creation

## 💻 Local Development

### Prerequisites

- Node.js (LTS version)
- pnpm (recommended) or npm
- Git

### Setup

```bash
# Clone the repository
git clone https://github.com/izuc/website-live.git
cd website-live

# Install dependencies
pnpm install

# Start development server
pnpm dev
```

### Available Scripts

- `pnpm dev` - Start development server
- `pnpm build` - Build for production
- `pnpm start` - Run production build locally
- `pnpm test` - Run test suite
- `pnpm lint:fix` - Fix linting issues

## 🐳 Docker Support

```bash
# Build the Docker image
pnpm run dockerbuild

# Run with Docker Compose
docker compose --profile development up
```
