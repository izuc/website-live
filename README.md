# Website.Live

Transform your ideas into stunning websites with the power of AI.

## Features

- **AI-Powered Development**: Build websites faster with intelligent AI assistance
- **Modern Tech Stack**: Latest technologies and best practices built-in
- **Instant Deployment**: Go live with your website in minutes
- **Multiple LLM Support**: Choose from various AI models including OpenAI, Anthropic, and more
- **Real-time Preview**: See your changes instantly in the built-in preview
- **Integrated Terminal**: Execute commands and see output directly in the interface
- **File Management**: Easy file upload, download, and management
- **Version Control**: Track changes and revert when needed

## Getting Started

1. Visit [Website.Live](https://website.live)
2. Choose your preferred AI model
3. Start building your website with natural language commands
4. Preview and deploy your creation

## Development

### Prerequisites

- Node.js (LTS version)
- pnpm (recommended) or npm

### Setup

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev
```
