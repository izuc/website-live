# Website.Live FAQ

## General Questions

### What is Website.Live?
Website.Live is an AI-powered web development platform that helps you build and deploy websites quickly using natural language commands.

### How does it work?
Simply describe what you want to build, and our AI will help you create it. You can interact with the AI to refine your website's design, add features, and make changes in real-time.

### What technologies does it use?
Website.Live uses modern web technologies including:
- React for the frontend
- TypeScript for type safety
- Tailwind CSS for styling
- Various AI models for development assistance

## Features

### What AI models are supported?
We support multiple AI providers including:
- OpenAI
- Anthropic
- Gemini
- And more...

### Can I deploy my website?
Yes! You can deploy your website directly from the platform. We provide easy deployment options and hosting solutions.

### Can I use my own domain?
Yes, you can connect your own domain to your Website.Live project.

## Development

### How do I run it locally?
1. Clone the repository
2. Install dependencies with `pnpm install`
3. Start the development server with `pnpm dev`

### How do I contribute?
Check our [Contributing Guide](CONTRIBUTING.md) for detailed information on how to contribute to the project.

## Troubleshooting

### Common Issues
1. **API Key Issues**: Make sure your API keys are properly configured in your environment variables.
2. **Build Errors**: Ensure you have the latest dependencies installed.
3. **Preview Issues**: Check your browser console for any error messages.

## Security

### How are API keys handled?
API keys are stored securely and never exposed in the client-side code. We follow best practices for security and data protection.

### Is my code secure?
Yes, your code and data are protected. We use secure connections and follow industry-standard security practices.
